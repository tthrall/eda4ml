## Chapter 8: Text Analysis — Review

**File**: text-analysis.qmd | **Lines**: 696 | **Sections**: 10

---

### Core Concept

Introduction to text-as-data: tokenization, term frequency, tf-idf, document-term matrices, and topic modeling. Positions text analysis as EDA applied to unstructured data, bridging traditional statistics with NLP.

---

### Key Skills

- Tokenize text using `tidytext::unnest_tokens()`
- Remove stop words with `anti_join()`
- Calculate term frequencies and tf-idf
- Work with document-term matrices (DTM/DFM)
- Convert between tidy and matrix formats
- Apply LDA topic modeling
- Interpret topic-term probabilities

---

### Mathematical Prerequisites

**Minimal.** Requires only logarithms (for tf-idf and log-ratios) and basic probability (for LDA interpretation). This is the most accessible chapter mathematically, making it a welcome change of pace after Chapters 6-7.

### Strengths

1. **Code is shown!** (lines 75, 89, 104, etc.): Unlike previous chapters, `echo: true` appears on key code blocks. Students see `unnest_tokens()`, `anti_join()`, `bind_tf_idf()` in action. This is a significant improvement.
2. **Memorable opening example** (lines 54-68): Macbeth's "sound and fury" speech is engaging and short enough to trace through completely
3. **Contrasting authors** (Austen vs. Wells): Comparing romance novels to science fiction makes the vocabulary differences intuitive
4. **Clear tf-idf explanation** (lines 309-332): Mathematical definitions with LaTeX, then immediate application to Austen novels
5. **Practical format conversions** (lines 388-395): The `tidy()` ↔ `cast_*()` workflow addresses a real pain point in text analysis
6. **LDA visualization** (lines 600-656): The log-ratio bar chart comparing topic-term probabilities is an effective way to interpret topics
7. **Class exercise** (lines 305-308): Finally, an in-class team activity!
8. **Good resources section** (lines 683-696): Links to Silge & Robinson book, CRAN Task View, original LDA paper

---

### Weaknesses

1. **Data loading complexity** (lines 220-256): The `hgwells_lines` code with three alternative loading methods (`uncl_download`, `load_rda`, `read_tsv`) is confusing and fragile. Students will wonder which path executes.
2. **Gutenberg API dependency**: Package `gutenbergr` relies on an external API that may be unreliable. The fallback to local files is pragmatic but adds complexity.
3. **LDA code workaround** (lines 525-556): The comment "TODO: overcome error generated by tidy(ap_lda)" suggests a compatibility issue. Students will see a workaround rather than the intended clean code.
4. **No word embedding discussion**: The "Additional Aspects" section (lines 660-672) lists word embeddings but doesn't explain them. Given the importance of word2vec/GloVe to modern NLP, even a brief conceptual explanation would help.
5. **No connection to linear algebra**: Word embeddings and LDA both have matrix factorization interpretations. A sentence connecting to Chapter 7's SVD would strengthen the book's coherence.
6. **Limited EDA framing**: The chapter teaches text analysis methods but doesn't explicitly discuss how to _explore_ text data—what questions to ask, what patterns to look for, how to iterate.
7. **Missing stemming/lemmatization**: Students should know these concepts exist, even if the chapter doesn't implement them

---

### EDA Connection

**Implicit.** Word frequency tables and tf-idf rankings are exploratory, but the chapter doesn't frame them as EDA tools. A paragraph stating "when you encounter a new text corpus, start by examining word frequencies, identifying distinctive terms via tf-idf, and considering topic models for thematic structure" would help.

---

### Knox Handoff (ML Preparation)

**Moderate.** Topic modeling (LDA) connects to unsupervised learning, and tf-idf features are commonly used in text classification. However, the chapter doesn't discuss:

- Text classification (supervised learning on text)
- Word embeddings as features
- Deep learning approaches (transformers, BERT)

A brief forward-looking paragraph would help students understand where these techniques fit in the ML landscape.

---

### Overall Assessment

**This is a well-executed introductory chapter.** The scope is appropriate, the examples are engaging, and—crucially—the code is visible. At 696 lines, it's the right length for an introduction to text analysis.

The main weaknesses are technical (data loading complexity, LDA workaround) rather than pedagogical. The chapter successfully demonstrates that the tidy data principles from earlier chapters extend to text data.

**This chapter shows what the book does well when properly scoped.** Compare to Chapter 7's 4,516 lines covering PCA, LDA, SVD, and nonlinear methods—this chapter focuses on one topic and executes it cleanly.
