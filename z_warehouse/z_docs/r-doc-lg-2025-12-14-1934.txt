LearningGraph: A Knowledge Graph for Skills-Based Learning
Description
A multi-relational knowledge graph representing the data science skills ecosystem, designed for demonstrating graph theory concepts in machine learning applications.

Format
A list with the following components:

metadata
List with name, description, source, version, schema

proficiency_levels
Tibble defining the 0-4 proficiency scale

nodes
List of node tables:

competencies
7 competency areas from IC CRG

skills
18 knowledge/skills (KSAs) curated for EDA4ML scope

work_roles
3 data science job roles

courses
15 courses covering all 18 skills

learners
6 fictional learner profiles

edges
List of edge tables:

has_skill
Learner -> Skill with proficiency (37 edges)

requires_skill
Work Role -> Skill with threshold (25 edges)

prerequisite
Skill -> Skill, conceptual dependencies (22 edges)

course_prereq
Course -> Course, curricular ordering (19 edges)

teaches
Course -> Skill with level taught (19 edges)

Individual components are also exported: lg_proficiency_levels, lg_competencies, lg_skills, lg_work_roles, lg_courses, lg_learners, lg_has_skill, lg_requires_skill, lg_prerequisite, lg_course_prereq, lg_teaches, lg_schema.

Graph Structure
DAG: Skill and course prerequisites form directed acyclic graphs

Bipartite: Learner-Skill and Course-Skill relationships

Weighted: Proficiency levels as edge weights

Multi-relational: Multiple edge types between node types

Proficiency Framework
Work role requirements follow typical career progression:

Entry/Mid (2-5 yrs): concentration skills at level 2, supporting at 1-2

Mid (3-5 yrs): concentration skills at 2-3, supporting at 2

Senior (5+ yrs): concentration skills at 3, supporting at 2

Level 4 (Master) is reserved for thought leaders, not job requirements.

Course Structure
The 15 courses cover all 18 skills. Entry points (no prerequisites): C01 (Programming), C03 (Probability), C04 (Linear Algebra). Course design inspired by Georgia Tech OMSA, UC Berkeley MIDS, Stanford MS Statistics, CMU MSML, and JHU MS Data Science.

Complementary Prerequisite Views
prerequisite (skill -> skill): Conceptual dependencies

course_prereq (course -> course): Curricular ordering

These are complementary; courses bundle skills, so course prerequisites don't derive directly from skill prerequisites.

Source
Based on the Competency Resource Guide for Data Science (2023), Office of the Director of National Intelligence (UNCLASSIFIED). Structure inspired by Workera.ai's skills intelligence platform.
