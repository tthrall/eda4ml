eda4ml/code/

Supporting R scripts for Exploratory Data Analysis for Machine Learning.

Sync note: A copy of this directory exists at eda4ml-slides/code/ for slide deck builds. This (eda4ml/code/) is the canonical source. Synchronize before major slide releases.

Package note: Many datasets originally generated by scripts in this directory are now available via the companion package eda4mlr. Prefer data(dataset_name) from the package over sourcing these scripts directly.

Usage

For datasets: Use eda4mlr package when available:

library(eda4mlr)
data(wine_quality)
data(learning_graph)
data(lg_skills)

For utilities: Source scripts as needed from chapter .qmd files: - Learning graph diagnostics (lg_diagnostics.R, graph_helpers.R) — Chapter 15 - Text helpers — Chapters 10–11 (text analysis, topic models) - Spectral/time series (spectrum_helpers.R, pgram_grid.R) — Chapters 12–14 - eda4ml_admin.R — project-wide monitoring utilities
