# eda4ml/code/

Supporting R scripts for *Exploratory Data Analysis for Machine Learning*.

> **Sync note**: A copy of this directory exists at `eda4ml-slides/code/` for slide deck builds. This (`eda4ml/code/`) is the canonical source. Synchronize before major slide releases.

> **Package note**: Many datasets originally generated by scripts in this directory are now available via the companion package [`eda4mlr`](https://github.com/tthrall/eda4mlr). Prefer `data(dataset_name)` from the package over sourcing these scripts directly.

### Visualization and geometry

| File | Purpose |
|------|---------|
| `lda_2D.R` | LDA visualization: simulate mixture data, compute class-conditional statistics, decision boundaries, scatter plots with boundary segments |
| `pc_aesthetics.R` | PCA plotting: standard axis colors, rotation matrix sign repair (ensure positive determinant), segment endpoints, rotation-to-tibble conversion |
| `pgram_grid.R` | Tessellate 2D/3D with parallelograms/parallelepipeds; histogram utilities via Freedman-Diaconis rule |
| `interval_grid.R` | Partition real line into congruent segments; compute interval midpoints for binning |

### Statistical and mathematical utilities

| File | Purpose |
|------|---------|
| `d_ball.R` | Curse of dimensionality: d-ball volume/surface, cube-to-ball ratios, norm statistics for uniform distributions on hypercubes |
| `f_divergence.R` | f-divergence kernels: KL, exponential, Hellinger, Jeffreys, χ², total variation; evaluation across density ratios |
| `z_score.R` | Standardization: z-score (mean/sd), robust score (median/IQR), inverse normal transforms to [0,1], test functions |
| `rmse_per_grp.R` | Group-wise point-to-centroid distances: compute deviations from group means and Euclidean norms |
| `xtabs_to_jaccard.R` | Convert cross-tabulation counts to Jaccard similarity; compute weighted average similarity |
| `spectrum_helpers.R` | Spectral analysis: extract density from `astsa::arma.spec()`, format `stats::spec.pgram()` output as tibbles |

## Usage

**For datasets**: Use `eda4mlr` package when available:
```r
library(eda4mlr)
data(wine_quality)
data(learning_graph)
data(lg_skills)
```

**For utilities**: Source scripts as needed from chapter `.qmd` files:
- **Learning graph diagnostics** (`lg_diagnostics.R`, `graph_helpers.R`) — Chapter 15
- **Text helpers** — Chapters 10–11 (text analysis, topic models)
- **Spectral/time series** (`spectrum_helpers.R`, `pgram_grid.R`) — Chapters 12–14
- **`eda4ml_admin.R`** — project-wide monitoring utilities
